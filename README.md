# 🚗 Road Accident Dashboard

## 📊 Project Overview

The **Road Accident Dashboard** is an interactive data analytics project designed to analyze road accident data and identify important patterns, trends, and risk factors.

The dashboard provides insights into accident frequency, casualties, accident severity, road conditions, vehicle types, weather conditions, and other factors to help understand road safety trends and support data-driven decision-making.

## 🎯 Objectives

* Analyze overall road accident trends.
* Identify accident-prone conditions and locations.
* Analyze casualties by severity.
* Understand the impact of weather and road conditions.
* Compare accidents by vehicle type.
* Track monthly and yearly accident trends.
* Create an interactive dashboard for easy data exploration.

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development & visualization
* **Microsoft Excel** – Data cleaning and preprocessing
* **Power Query** – Data transformation
* **DAX** – Calculated measures and KPIs
* **Data Visualization** – Charts, cards, maps, and interactive filters

## 📌 Key KPIs

The dashboard tracks important metrics such as:

* **Total Accidents**
* **Total Casualties**
* **Fatal Casualties**
* **Serious Casualties**
* **Slight Casualties**
* **Accident Severity**
* **Monthly Accident Trends**
* **Vehicle Type Analysis**

## 📈 Dashboard Features

### 1. Accident Overview

Provides a high-level summary of total accidents and casualties using interactive KPI cards.

### 2. Accident Trend Analysis

Shows how accidents and casualties change over time using monthly and yearly trend analysis.

### 3. Accident Severity Analysis

Analyzes accidents based on severity categories such as:

* Fatal
* Serious
* Slight

### 4. Vehicle Analysis

Examines accidents and casualties associated with different vehicle types.

### 5. Road & Weather Conditions

Analyzes the relationship between accidents and factors such as:

* Road surface conditions
* Weather conditions
* Light conditions
* Road type

### 6. Interactive Filters

Users can dynamically filter the dashboard based on available dimensions such as:

* Date
* Accident severity
* Vehicle type
* Weather condition
* Road condition
* Location
